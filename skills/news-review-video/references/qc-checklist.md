# Чек-лист приёмки выпуска

либо попадает в отчёт с причиной.

## 0. Перед началом

- [ ] Прочитаны `references/style-standard.md` и `references/insert-sourcing.md`.
- [ ] Зафиксирован бриф: тема, длина, число блоков, формат кадра, площадка.
- [ ] Есть папка проекта с `assets/raw/`, `assets/work/`, `assets/sources.json`.
- [ ] Проверена версия CLI: `tsrct --version` совпадает с пином скилла (0.3.1).

## 1. Материал

- [ ] У каждого блока есть первоисточник, и он открывается.
- [ ] Все врезки скачаны локально; `assets/raw/` не пустой.
- [ ] Каждый файл в монтаже имеет запись в `assets/sources.json` (поля не пропущены).
- [ ] Для фактов без второго источника есть формулировка «по данным <источник>».
- [ ] Нет сгенерированных изображений, поданных как реальные материалы события.
- [ ] Скриншоты сняты с реальных страниц, текст в них не переписан.
- [ ] У каждой врезки есть атрибуция (издание/канал + дата).

## 2. Монтаж

- [ ] Интро-тизер 45–75 с, темп 20–30 резов/мин.
- [ ] 15–25 блоков, каждый: карточка-заголовок → VO → врезки → вывод.
- [ ] Врезка каждые 4–8 с внутри блока.
- [ ] Визуал меняется каждые 2,5–5 с: рез, наезд, плашка, вырезка, подсветка или графика.
- [ ] Каждый стоп-кадр, фото и скриншот имеет движение: наезд, выезд, панораму или
      подсветку (скорость 3–6 % масштаба в секунду).
- [ ] Нет замороженных кадров ≥ 2 с и «спокойных» участков ≥ 10 с.
- [ ] Нет плана без смены визуала дольше 30 с.
- [ ] Нет чёрных кадров, случайных стопов, рассинхрона звука.

Проверка по факту:

```powershell
python "$env:USERPROFILE\.agents\skills\news-review-video\scripts\measure_pacing.py" `
  render\episode-1080p.mp4 --intro 66 --json render\pacing-report.json
```

Ожидаемый результат: `ИТОГ: соответствует стандарту`, либо разбор отклонений в отчёте.

## 3. Текст и речь

- [ ] VO ≈ 140 слов/мин (проверить: слова ÷ минуты по блокам).
- [ ] Нет длинных пауз; речь идёт непрерывно.
- [ ] Имена, должности, даты, цифры сверены с первоисточниками.
- [ ] Ударения и произношение спорных названий проверены.
- [ ] Тире, кавычки, ё — по правилам; титры без опечаток.

## 4. Графика

Построение (проверяется по исходникам):

- [ ] Графика собрана кодом: композиции лежат в `graphics/<блок>/`, а не нарисованы
      прямоугольниками и текстовыми слоями внутри проекта.
- [ ] `npx hyperframes check` — 0 ошибок, контраст WCAG AA пройден.
- [ ] Перед ручной сборкой проверен реестр HyperFrames на готовые блоки.
- [ ] Оверлеи отрендерены с альфой: `ffprobe` показывает `prores / yuva444p12le`.
- [ ] Ни один оверлей не отрендерен как WebM: `import-video` принимает только MP4/MOV/M4V.
- [ ] Разрешение и fps оверлеев совпадают с проектом (без масштабирования).

Содержание:

- [ ] Карточки блоков с номерами и заголовками на месте.
- [ ] Нижние плашки с именем и должностью при первом появлении человека.
- [ ] Цитаты с источником, поверх затемнённой подложки.
- [ ] Карты/схемы/цифры анимированы, появляются с движением.
- [ ] Текст не перекрывает лица и ключевые объекты, поля ≥ 5 %, контраст ≥ 4,5:1.
- [ ] Одна гарнитура на выпуск (максимум два начертания).
- [ ] Каталог «выездов» соблюдён: плашки СМИ с настоящим логотипом и наклоном −2°…+3°,
      вырезки персонажей без фона, посты соцсетей в родной стилистике, документы с анимированным
      маркером, карты с прорисовкой маршрута, архив в рамке с таймкодом
      (`tesseract-video/references/investigative-news-style.md`).

Композит и качество картинки:

- [ ] Контактный лист: 6 кадров оверлея на светлом и тёмном фоне — края чистые, без ореолов.
- [ ] Сквозь прозрачные области оверлея виден футаж, а не чёрный кадр.
- [ ] Нет бандинга, дрожания на медленных движениях и «духов» на быстрых.
- [ ] Текст в кадре покоя резкий; на уменьшении до 1/4 размера читается.
- [ ] Появление и уход графики совпадают со словом VO и с битом музыки.
- [ ] Нет запрещённых приёмов: свечение, стекло, многоцветные градиенты, эмодзи,
      частицы, ударные волны, RGB-сдвиг, тряска камеры, пружинный отскок, два
      одинаковых приёма подряд.
- [ ] Графика не перекрывает лицо говорящего и ключевой объект кадра.

## 5. Звук

- [ ] Музыкальная подложка есть, ducking −12…−18 дБ под VO.
- [ ] Вжухи на резах и появлениях графики, импакт на смене блока.
- [ ] Пауза 0,3–0,6 с перед ключевой цифрой или цитатой.
- [ ] Нет обрывов музыки на стыках, переходы кроссфейдом.
- [ ] Громкость: интегрально около −14 LUFS, истинный пик ≤ −1 дБTP
      (`ffmpeg -i render.mp4 -af loudnorm=print_format=summary -f null -`).

## 6. Техника и выдача

- [ ] Разрешение и fps едины по всему выпуску (1920×1080, 25 или 30 fps).
- [ ] H.264 + AAC, воспроизводится локально без артефактов.
- [ ] `.tsrct` сохранён, все ассеты внутри проекта, проект открывается.
- [ ] Экспорт в Adobe получен через `tesseract_adobe.py`: Premiere Pro XML и After Effects
      JSX / ProRes 4444; дорожки, резы и уровни звука в XML сохранены.
- [ ] Рядом с рендером лежат `assets/sources.json` и `pacing-report.json`.
- [ ] В отчёте перечислены отклонения от стандарта и их причины.

## 7. Если проверка не прошла

| Что не прошло | Что делать |
|---|---|
| Тело < 5 резов/мин | добавить врезки внутрь блоков, разбить длинные планы |
| Тело > 12 резов/мин | удлинить планы, убрать дробление ради дробления |
| Интро < 18 резов/мин | пересобрать тизер на 2–3-секундных планах |
| Замороженный участок | назначить движение наезда/панорамы или заменить материал |
| Спокойный участок ≥ 10 с | добавить графику, смену состояния или вторую картинку |
| План без реза > 30 с | разбить врезкой, не ломая смысл; если нельзя — объяснить в отчёте |
| Нет записи в ledger | добавить запись или убрать материал из монтажа |
