# Поиск, загрузка и учёт стороннего материала

Правило первое: **нет файла без записи в ledger**. Материал без источника в монтаж не идёт.

Правило второе: **врезка должна быть про это событие**. Стоковая картинка «в тему» вместо
кадра события — брак (см. [стандарт стиля](style-standard.md), раздел 4).

## 1. Приоритет источников

| Уровень | Что это | Примеры |
|---|---|---|
| 1 | Первоисточник | заявление ведомства, пост автора события, официальный документ, релиз компании |
| 2 | Официальные каналы | пресс-службы, аккаунты ведомств и компаний, официальные YouTube-каналы |
| 3 | Агентства и крупные СМИ | Reuters, AP, AFP, ТАСС, «Интерфакс», РИА, BBC, местные издания |
| 4 | Архивы и репозитории | Wikimedia Commons, архивы пресс-фото, Wayback Machine |
| 5 | Сток (только фон) | Pexels, Pixabay, Coverr — для нейтральных перебивок, не для события |

Для музыки, SFX, озвучки и стоковых перебивок используй скилл `media-use` (Agent Media OS):
он подбирает и закрепляет локальный файл. Здесь описана загрузка **новостного** материала.

## 2. Инструменты (проверены на этой машине)

| Задача | Инструмент | Путь |
|---|---|---|
| Скачать видео/аудио с YouTube, VK, Rutube и др. | yt-dlp | `%LOCALAPPDATA%\Programs\yt-dlp\yt-dlp.exe` |
| Субтитры и метаданные (без видео) | yt-dlp | `--skip-download --write-auto-subs --write-info-json` |
| Нарезка, конвертация, склейка, замеры | ffmpeg | `ffmpeg` (в PATH, `C:\WINDOWS\ffmpeg.exe`), `ffprobe` (`C:\ffmpeg\bin\ffprobe.exe`) |
| Скриншот статьи целиком | Edge headless | `"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless=new --disable-gpu --hide-scrollbars --window-size=1440,4000 --screenshot="out.png" "<url>"` |
| Скриншот (альтернатива) | Chrome headless | `"C:\Program Files\Google\Chrome\Application\chrome.exe"` — те же ключи |
| Скачать файл/картинку/PDF | `Invoke-WebRequest` | `-OutFile`, при необходимости `-UserAgent` |

Если yt-dlp отсутствует, он ставится одним файлом:
`Invoke-WebRequest https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp.exe -OutFile "$env:LOCALAPPDATA\Programs\yt-dlp\yt-dlp.exe"`.

## 3. Рабочие рецепты

**Видео события с YouTube/канала издания** (низкое разрешение для чернового монтажа,
высокое — для финала):

```powershell
$yt = "$env:LOCALAPPDATA\Programs\yt-dlp\yt-dlp.exe"
# метаданные, главы и субтитры — без скачивания видео
& $yt --no-simulate --skip-download --write-info-json --write-auto-subs --sub-langs "ru.*,en.*" `
      -o "assets\raw\src.%(ext)s" "<URL>"
# фрагмент 0:30–2:10 в 1080p
& $yt -f "bv*[height<=1080]+ba/b[height<=1080]" --download-sections "*0:30-2:10" `
      --force-keyframes-at-cuts -o "assets\raw\event.%(ext)s" "<URL>"
```

**Скриншот статьи или поста** (обязательно потом двигать наездом или панорамой):

```powershell
$edge = "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
& $edge --headless=new --disable-gpu --hide-scrollbars --virtual-time-budget=8000 `
        --window-size=1440,3000 --screenshot="assets\raw\post-<slug>.png" "<URL>"
```

**Картинка или PDF** (документ, фото с сайта ведомства):

```powershell
Invoke-WebRequest "<URL>" -OutFile "assets\raw\<publisher>-<slug>.<ext>" -UserAgent "Mozilla/5.0"
```

**Аудио события/интершум**: вытягивается из скачанного видео —
`ffmpeg -i event.mp4 -vn -c:a aac -b:a 192k assets\raw\event-mix.m4a`.

**Фактическая проверка кадра**: кадр должен соответствовать событию, а не быть архивом.
Берёшь 2–3 кадра из видео (`ffmpeg -ss <t> -i event.mp4 -frames:v 1 check.png`) и сверяешь
с описанием и датой в первоисточнике.

## 4. Достоверность: обязательные проверки

1. **Минимум два независимых источника** на факт; если есть только один — это указывается
   в отчёте, а в тексте формулируется как утверждение источника, а не как факт.
2. **Дата и место**: у материала есть дата публикации и, для видео, привязка к событию.
   Перезалив без первоисточника не используется.
3. **Скриншот — настоящий**: снят с реальной страницы, текст в нём не переписывается и не
   дорисовывается. Допустимо кадрировать, увеличивать, подсвечивать и затемнять.
4. **Фейковые доказательства запрещены**: сгенерированные изображения, постановочные кадры
   и «реконструкции» не подаются как реальные материалы события.
5. **Обратный поиск изображения** (Google Lens / Yandex) — если фото пришло из соцсетей без
   первоисточника; результат проверки фиксируется в ledger.
6. **Сомнение — в отчёт**: если достоверность не подтверждена, материал не ставится в
   монтаж, а факт либо убирается, либо подаётся как неподтверждённый.

## 5. Права и атрибуция

- Короткие фрагменты чужих видео и фото используются в информационных и обзорных целях,
  с обязательной атрибуцией на экране (издание/канал + дата) и полной ссылкой в ledger.
- Музыка — только лицензированная (через `media-use`), чужие треки не используются.
- Логотипы и плашки изданий не перерисовываются; скриншот показывается как есть.
- Риск блокировки на площадке из-за чужого материала фиксируется в отчёте, если
  фрагменты длиннее 30 секунд или их много.

## 6. Ledger: `assets/sources.json`

Обязательный файл проекта. Одна запись — один использованный файл:

```json
{
  "generatedAt": "2026-10-10T12:00:00Z",
  "episode": "Выпуск: <тема>",
  "assets": [
    {
      "file": "assets/raw/ria-flydubai-2026-10-01.mp4",
      "kind": "video",
      "publisher": "РИА Новости",
      "author": "пресс-служба",
      "title": "Кадры из салона самолёта после посадки",
      "url": "https://...",
      "publishedAt": "2026-10-01",
      "retrievedAt": "2026-10-10T11:20:00Z",
      "level": 3,
      "usage": "короткий фрагмент 0:12–0:19, обзорный сюжет, атрибуция на экране",
      "verification": "совпадает с релизом перевозчика и репортажем ТАСС от 01.10",
      "usedIn": ["block-01", "block-04"]
    }
  ]
}
```

Схема записи: `file`, `kind` (video/photo/screenshot/document/audio/stock), `publisher`,
`author`, `title`, `url`, `publishedAt`, `retrievedAt`, `level` (1–5 из таблицы выше),
`usage`, `verification`, `usedIn`. Отсутствие любого поля = запись неполная.

## 7. Хранение

```
<project>/
  assets/raw/        исходники как скачаны (не перезаписывать)
  assets/work/       подготовленные: нарезка, стабилизация, апскейл
  assets/sources.json
  graphics/<блок>/   композиции графики (HyperFrames) и их рендеры
  episode.tsrct
  render/episode-1080p.mp4
```

Файлы называются `<издание>-<слаг>-<дата>.<ext>`. Исходники не удаляются до сдачи выпуска:
по ним проверяется достоверность и восстанавливается монтаж при пересборке.
