# Пример: нижняя плашка и цифра в стиле выпуска

Рабочая композиция HyperFrames — та самая, на которой проверялся пайплайн из
[графики кодом](../../references/graphics-pipeline.md). Плашка с именем и должностью плюс
счётчик-цифра, движение по измеренным нормам.

Что внутри:

- фон прозрачный (у `html/body` нет `background`) — файл годится для альфа-оверлея;
- появление на `expo.out`, без перелёта; уход на `power3.in` и короче входа;
- строка имени выезжает из обрезки (`overflow: hidden` + `yPercent`);
- цифра считается на `expo.out`, табличные цифры, после остановки — выдержка;
- холд не замирает: масштаб ползёт 1,2 % за три секунды;
- один акцентный цвет, одна гарнитура, никаких свечений и градиентов.

```sh
cd examples/news-lower-third
npx hyperframes check                                                 # 0 ошибок
npx hyperframes render . --format mov -q high -o renders/overlay.mov  # альфа-оверлей
npx hyperframes render . --format mp4 -q high -o renders/plate.mp4    # просто посмотреть
```

Проверка альфы и композит в проекте — `../../references/graphics-pipeline.md` §3.
Плашка рассчитана на 1920×1080: для вертикали поменяй `data-resolution`, размеры и позиции.

`preview.png` — контактный лист этого рендера на светлом и тёмном фоне: так проверяются
края, альфа и ореолы.
