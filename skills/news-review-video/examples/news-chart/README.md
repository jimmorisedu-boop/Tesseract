# Пример: график в стиле выпуска

Готовый блок `data-chart` из реестра HyperFrames, переведённый на наши шрифт, палитру и русский
текст. Это эталон для любого графика в выпуске: показывает, что именно правится в реестровом
блоке, прежде чем он попадает в монтаж.

Рендер: 15 с, 1920×1080, 30 fps, полноэкранный MP4 (график не оверлей — он занимает весь кадр).

```sh
npm run check     # npx hyperframes check — 0 ошибок, кроме ложных по контрасту SVG
npm run render    # npx hyperframes render . --format mp4 -q high -o renders/chart.mp4
```

Для оверлея поверх футажа рендерь `--format mov -q high` (ProRes 4444 с альфой) и импортируй
`tsrct project import-video --project episode.tsrct --file renders/chart.mov --asset-id gfx-chart`.

## Что изменено против блока из реестра

| Что | В реестре | У нас |
|---|---|---|
| Гарнитура | `Libre Baskerville` (засечки) + `Libre Franklin`, шрифты с CDN | `Inter`, системный стек, без внешних запросов |
| Сцена | кремовая `#faf9f6`, текст `#333` | тёмная `#0b0b0c`, текст `#f5f5f4`, вторичный `#a8a29e` |
| Акцент | нет: столбцы серые, линия `#326fa8` (синева фреймворка) | один акцент выпуска `#e8402a` — только линия и её подписи |
| Столбцы | `#5c5c5c` — 2,5:1 к сцене, ниже нормы 3:1 | `#71717a` — 4,08:1, видно после сжатия YouTube |
| Копирайт | `Monthly Revenue vs. Conversion Rate`, `Source: Internal analytics` | заголовок-утверждение «Выручка растёт, конверсия отстаёт», период и единицы, источник |
| Ось | `Jan … Jun` | `янв … июн` |
| Цифры | пропорциональные | `font-variant-numeric: tabular-nums` — счётчик не дёргает ширину |
| Кегли | заголовок 42 px, подписи 11–16 px | заголовок 56 px, подписи 18–20 px, источник 14 px |

## Проверено на кадре

`python ../scripts/graphics_qc.py preview.png`:

```
фон #080808 91,3 %; столбцы #707078 6,3 % — 4,08:1 (норма 3:1);
текст #f0f0e8 17,49:1 (норма 4,5:1); доля акцента 0,16 % (норма ≤ 8 %);
запрещённых цветов нет; копия 480 px читается
```

До перевода блока на наши токены: сцена `#f0f0f0` 91,9 %, акцент в кадре 0,00 %, засечки и
английский текст. Контраст при этом был в норме — то есть «плохо выглядит» это не про метрику
контраста, а про решение: чужая гарнитура, чужая палитра, чужой язык, нет акцента.

## Ловушка `hyperframes check`

Чекер выдаёт 6 ошибок контраста на подписях оси внутри под-композиции (`3.43:1`, подсказка
`rgb(121,121,121)`). Значение **не меняется** при смене цвета текста: проверено и с `#a8a29e`, и с
почти белым `#f5f5f4`. Это ложное срабатывание на SVG внутри под-композиции — подсказка чекера
на тёмной сцене только ухудшила бы читаемость. Реальный контраст меряется по кадру
(`scripts/graphics_qc.py`).

## Как адаптировать под свой выпуск

1. Замени `months`, `revenueData`, `conversionData` и подписи на числа из ledger
   (`assets/sources.json`). Никаких круглых значений «для красоты».
2. Заголовок — утверждение о данных, не название темы: «Выручка растёт, конверсия отстаёт»,
   а не «Выручка и конверсия».
3. Единицы и период — в подзаголовке; источник — на экране, внизу кадра.
4. Одна мысль на кадр. Если нужны две независимые истории — это два кадра, а не два графика.
5. Проверь `python ../scripts/graphics_qc.py <кадр.png>` и тест 480 px перед монтажом.
