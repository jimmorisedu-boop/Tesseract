Frequently Asked Questions

Does this work in Antigravity?

Yes! Antigravity possesses full local shell execution and workspace file access, allowing the Tesseract CLI (tsrct.cmd / tsrct) to run locally with full GPU acceleration.

Will it use my own media files?

Yes. Simply place your video files, audio tracks, fonts, and images in your workspace directory or attach them to Antigravity. Tesseract packages and edits them natively.

Where is the CLI runtime installed?

On Windows, the runtime installs to %LOCALAPPDATA%\Tesseract\bin\tsrct.cmd. On macOS, ~/Library/Application Support/Tesseract/bin/tsrct. On Linux, ~/.local/share/Tesseract/bin/tsrct.

Do I need both the plugin and the skills?

Installing Tesseract as an Antigravity plugin automatically registers all 5 skills (tesseract-video, tesseract-motion, tesseract-design, tesseract-editor) along with agent rules.
