Autonomous One-Prompt Agent Setup

Paste this prompt directly into a DeepSeek Harness session. The agent installs the skills, downloads the matching CLI binary, validates checksums, installs tsrct.cmd, and confirms runtime rendering:

Set up Tesseract by Mirage so you can create editable designs, edit videos, and make motion graphics in this DeepSeek Harness session. Install the four Tesseract skills from https://github.com/mirage-hq/Tesseract into a skill root DSH scans (~/.agents/skills or ~/.dsh/skills), check this system's environment, download the required Tesseract CLI (v0.3.1) matching my architecture, verify the SHA-256 checksum, run the installer, and verify `tsrct --version`. Confirm a short preview renders correctly. Then ask me for my footage or the video/motion project I want to create. Keep the editable .tsrct project and source assets with the finished render.

One command (shared skills directory)

npx skills add mirage-hq/Tesseract

Manual installation (PowerShell / Windows)

git clone https://github.com/mirage-hq/Tesseract.git "$HOME\Tesseract" $dst = "$HOME\.agents\skills" # or: "$HOME\.dsh\skills" New-Item -ItemType Directory -Force $dst | Out-Null Copy-Item -Recurse -Force "$HOME\Tesseract\skills\*" $dst

Manual installation (macOS / Linux)

git clone https://github.com/mirage-hq/Tesseract.git ~/Tesseract mkdir -p ~/.agents/skills cp -R ~/Tesseract/skills/* ~/.agents/skills/
Sandbox note: DeepSeek Harness confines file writes to the session workspace by default. Keep the .tsrct project, imported assets, and renders inside that folder. Installing the CLI runtime under %LOCALAPPDATA% (or the platform equivalent) is outside the workspace, so DSH asks for approval first — that prompt is expected.

Where DeepSeek Harness finds skills

DSH discovers a directory bundle <name>/SKILL.md or a flat <name>.md at the top level of these roots, and watches them — new skills appear without a restart.

Rank Root Scope
100 <projectRoot>/.dsh/skills DSH-only skills inside one repository
200 <projectRoot>/.agents/skills Shared project skills
300 configured customSkillDirs Extra local roots
400 ~/.dsh/skills Global, DSH-only
500 ~/.agents/skills Global, shared across agents (where npx skills add writes)

The project root is the nearest ancestor containing .git. Because DSH reads skills straight from disk, Tesseract needs no DSH plugin package — the four skill bundles are the whole integration. For persistent CLI and version rules, add the Tesseract block from docs/deepseek.md to ~/.dsh/AGENTS.md.

House style for news-review episodes

A fifth skill turns the four capabilities into a repeatable news-roundup format.

news-review-video defines the delivery standard for news roundups, weekly digests, and commentary episodes. It ships with the measured profile of the reference episode, so the pacing rules are numbers, not taste.

RuleValue
Intro teaser45–75 s, 20–30 cuts/min
Episode body5–12 cuts/min, a new insert every 4–8 s
Every still, photo, screenshotmust move — push-in, pull-out, pan, or highlight at 3–6 % scale per second
Frozen framesnone ≥ 2 s; no low-motion stretch ≥ 10 s
Third-party insertsreal material only, downloaded locally, one provenance record per file
Deliveryrender + editable .tsrct + assets/sources.json + pacing report

Check the pacing of a finished render

python "$env:USERPROFILE\.agents\skills\news-review-video\scripts\measure_pacing.py" ` render\episode-1080p.mp4 --intro 66 --json render\pacing-report.json
Global rules: point ~/.dsh/AGENTS.md at the skill so every session applies the standard automatically. The skill's references/ folder carries the full style standard, the insert-sourcing workflow (yt-dlp, headless screenshots, ledger schema), and the acceptance checklist.

Graphics: built as code, composited as overlays

On-screen graphics are code, not timeline layers — the difference between a modern explainer and a template.

Lower thirds, headline cards, stat count-ups, quotes, maps and highlights are authored as HTML/CSS/SVG + GSAP compositions (HyperFrames), rendered to video, and composited inside the Tesseract project. An alpha overlay carries anything that sits over footage; a full-frame MP4 carries diagrams, timelines and charts.

StepCommand
Check the compositionnpx hyperframes check
Render the overlay (ProRes 4444, real alpha)npx hyperframes render . --format mov -q high -o renders/overlay.mov
Bring it into the edittsrct project import-video --project episode.tsrct --file renders/overlay.mov --asset-id gfx-plashka
Render the episodetsrct export --project episode.tsrct --output episode.mp4 --format mp4 --resolution 1080p --fps 30
Two constraints worth knowing: import-video accepts only MP4, MOV and M4V — an alpha WebM is rejected — and --resolution 4k cannot be combined with --format mov/webm, because that path has no alpha channel. Verified on this machine (HyperFrames 0.8.145, Node v25.2.1, tsrct 0.3.1): a 3-second render came out as prores / yuva444p12le and composited over footage with the transparent areas showing the video underneath.

Infographics: search the registry before drawing

Charts, maps and diagrams are searched for first — roughly 400 blocks already exist, and the good ones carry the typography and labels you would otherwise forget.

StepCommand
Search (392 items in 0.8.145)npx hyperframes catalog chart --json
Blocks onlynpx hyperframes catalog data --type=block
Install into the projectnpx hyperframes add data-chart --dir .
Acceptance on a framepython skills/news-review-video/scripts/graphics_qc.py frame.png

Verified names for news work: data-chart, chart-story, mk-line-graph, animated-bar-chart, bar-chart-race, decline-chart, count-up, number-wheel, mk-progress-stat, world-map, us-map*, flowchart, comparison-split, beat-timeline, lower-third-bild, code-diff, x-post, yt-comment-card.

A registry block is a frame, not a finished look. It ships its own fonts, palette and English copy — data-chart arrives with a serif headline and a cream #faf9f6 stage. Re-token it to the house style (one sans family, one accent, Russian labels, real data from the ledger) before it goes into an episode, or the episode reads as a patchwork of templates. And note that hyperframes check reports a false contrast failure on SVG labels inside a sub-composition: the measured number does not change when you change the text colour, so confirm against the rendered frame.

Verify the installation

Run these in the DeepSeek Harness session, from your project folder.

& "$env:LOCALAPPDATA\Tesseract\bin\tsrct.cmd" --version # expect: tsrct 0.3.1 (<revision>) & "$env:LOCALAPPDATA\Tesseract\bin\tsrct.cmd" project create -p smoke.tsrct & "$env:LOCALAPPDATA\Tesseract\bin\tsrct.cmd" preview -p smoke.tsrct -t 0.5 -o smoke-frame.png

A freshly created project is empty, so its first frame is a transparent PNG at the composition size — that already proves the renderer runs. To confirm real content renders, apply a rectangle action batch and preview again; the frame must contain the blue card (400×160 px at (80,80), RGBA [0.05,0.25,0.8,1]). The full command sequence is in docs/deepseek.md.

Frequently Asked Questions

Does this work in DeepSeek Harness?

Yes. DSH has local shell execution, workspace file access, and GPU access, so the Tesseract CLI (tsrct.cmd / tsrct) runs locally with full acceleration, and the skills are discovered straight from disk.

Do I need a DSH plugin or manifest?

No. DSH scans ~/.agents/skills, ~/.dsh/skills, and the project-local .agents/skills / .dsh/skills roots. Copying the four skill bundles is the complete integration — no restart required.

Will it use my own media files?

Yes. Place your video files, audio tracks, fonts, and images in the session workspace and tell the agent which files to use. Tesseract packages them into the project as editable assets.

Where is the CLI runtime installed?

On Windows, the runtime installs to %LOCALAPPDATA%\Tesseract\bin\tsrct.cmd. On macOS, ~/Library/Application Support/Tesseract/bin/tsrct. On Linux, ~/.local/share/Tesseract/bin/tsrct.

Why does the agent ask for approval during setup?

The runtime lives outside the DSH session workspace, and DSH confines writes to the workspace by default, so the install step needs an explicit approval. Skills themselves only need a user-level skill root.

Do I need both the plugin and the skills?

No. Installing Tesseract as skills registers all five capabilities (tesseract-video, tesseract-motion, tesseract-design, tesseract-editor, news-review-video) plus the runtime guidance. You don't need both.
